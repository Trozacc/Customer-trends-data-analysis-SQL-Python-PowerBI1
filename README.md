# Customer Shopping Behavior Analysis

End-to-end data analytics project analyzing customer shopping trends using **SQL**, **Python**, and **Power BI**.

## Project Overview

This project analyzes customer shopping behavior data to uncover insights about purchasing patterns, customer segmentation, revenue drivers, and product performance. The analysis spans the full data pipeline: data cleaning (Python), exploratory analysis (SQL), and interactive dashboarding (Power BI).

## Dataset

**Source:** `customer_shopping_behavior.csv` (3,900 records)

**Key Fields:**
- Customer demographics: `customer_id`, `age`, `gender`, `location`
- Purchase details: `item_purchased`, `category`, `purchase_amount`, `size`, `color`, `season`
- Behavioral: `previous_purchases`, `frequency_of_purchases`, `subscription_status`
- Transaction: `shipping_type`, `discount_applied`, `promo_code_used`, `payment_method`
- Feedback: `review_rating`

## Key Analyses (SQL)

1. **Revenue by Gender** - Total revenue generated by male vs female customers
2. **High-Value Discount Users** - Customers using discounts but spending above average
3. **Top-Rated Products** - Top 5 products by average review rating
4. **Shipping Impact** - Average purchase amount: Standard vs Express shipping
5. **Subscription Value** - Spend comparison: subscribers vs non-subscribers
6. **Discount Penetration** - Top 5 products by discount usage rate
7. **Customer Segmentation** - New / Returning / Loyal based on purchase history
8. **Category Leaders** - Top 3 products per category by order volume
9. **Loyalty & Subscription** - Correlation between repeat purchases and subscriptions
10. **Age Group Revenue** - Revenue contribution by age segment

## Python Workflow (Notebook)

- Data loading & inspection
- Column standardization (snake_case)
- Feature engineering: `age_group` (quartiles), `purchase_frequency_days` (mapping)
- Data quality checks (nulls, duplicate columns)
- PostgreSQL connection & data upload via SQLAlchemy

## Getting Started

### Prerequisites
- Python 3.8+
- PostgreSQL database
- Power BI Desktop (for `.pbix`)

### Setup

```bash
# Install Python dependencies
pip install pandas sqlalchemy psycopg2-binary jupyter

# Launch notebook
jupyter notebook Customer_Shopping_Behavior_Analysis.ipynb
```

### Database Setup
1. Create PostgreSQL database
2. Update connection string in notebook (cell 99+)
3. Run notebook to load cleaned data into `customer` table
4. Execute queries from `customer_behavior_sql_queries.sql`

### Power BI Dashboard
Open `customer_behavior_dashboard.pbix` in Power BI Desktop and connect to your PostgreSQL instance.

- **Gender parity** in revenue contribution
- **Subscribers spend significantly more** on average
- **Express shipping** correlates with higher order values
- **Loyal customers** (10+ prior purchases) drive disproportionate revenue
- **Discount-heavy products** show distinct category patterns
- **Age groups** reveal clear spending tier differences
